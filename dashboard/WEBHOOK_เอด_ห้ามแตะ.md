## ⚠️ ทำไมห้ามใช้ OA เดียวร่วมกัน
LINE ยิง event (ข้อความ/รูป/จอง) ไป webhook **URL เดียว** เท่านั้น:
- ชี้ Render → คอนเทนต์ไม่ได้รับ

- **ไม่มีทางได้ทั้งคู่** บน OA เดียว → ต้องแยก OA

*(ทางเลือกขั้นสูง: ทำ webhook proxy กระจาย event ไป 2 ระบบ — แต่เปราะบาง/เสี่ยง signature ไม่แนะนำ เทียบกับแยก OA ที่ชัวร์กว่า)*
