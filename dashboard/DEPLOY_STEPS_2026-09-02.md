## ส่วน A — Apps Script (ตัวจำเป็น แก้บั๊กค่าใช้จ่าย/กำไร)

**บัญชีที่ต้องใช้:** Google ของร้าน `saiyangsoi@gmail.com` (ต้อง login บัญชีนี้ก่อนเปิดลิงก์ด้านล่าง)

1. เปิด https://script.google.com/home ด้วยบัญชี `saiyangsoi@gmail.com`
2. ในรายการโปรเจกต์ ("โปรเจกต์ล่าสุด") หาโปรเจกต์ที่มีฟังก์ชันเหล่านี้อยู่ (เปิดดูในไฟล์ `.gs` ของโปรเจกต์):
   `importPosReports`, `sendDailyAlert`, `rebuildNow`, `setupDailyTrigger`
   ถ้ามีครบ 4 ชื่อนี้ = ใช่โปรเจกต์ที่ต้องแก้ (ปกติควรมีโปรเจกต์เดียวที่ตรงเงื่อนไขนี้)
3. **สำรองโค้ดเดิมก่อนทับ (สำคัญ กันแก้พลาดแล้วย้อนไม่ได้):**
   - ในหน้า Apps Script editor เปิดไฟล์หลัก (ไฟล์ที่มีโค้ดยาวที่สุด มักชื่อ `Code.gs` หรือ `Code_full.gs`)
   - กด `Ctrl+A` (Windows) หรือ `Cmd+A` (Mac) เลือกโค้ดทั้งหมด → `Ctrl+C`/`Cmd+C` คัดลอก
   - เปิด Google Docs ใหม่ (docs.new) วางโค้ดที่คัดลอกไว้ ตั้งชื่อไฟล์ว่า
     `Code_full_BACKUP_2026-09-02_ก่อนแก้บั๊กค่าใช้จ่าย` แล้วปล่อยไว้ (ไม่ต้องทำอะไรต่อ — ไว้ย้อนกลับถ้าพัง)
4. กลับไปที่ repo (`empro959/line-slip-bot`) เปิดไฟล์ `dashboard/Code_full.gs`
   (commit ปัจจุบันคือ `34468e3` — เนื้อโค้ดตัวที่แก้บั๊ก §3.12 แล้ว) เลือกทั้งหมด (`Ctrl+A`) แล้วคัดลอก
5. กลับไปที่ Apps Script editor → ไฟล์เดิมที่สำรองไว้ในข้อ 3 → เลือกทั้งหมด (`Ctrl+A`) → ลบ → วางโค้ดใหม่จากข้อ 4
6. กด **บันทึก** (ไอคอนรูปแผ่นดิสก์ หรือ `Ctrl+S`/`Cmd+S`)
7. เช็คว่าไม่มีเส้นสีแดงใต้โค้ด (syntax error) — ถ้ามี **หยุดทันที อย่ากด Save ซ้ำ/อย่ารันอะไร** แล้วแจ้งกลับมาที่ห้องนี้พร้อม screenshot
8. ไม่ต้องกดรันฟังก์ชันไหนเอง — trigger อัตโนมัติ (`importPosReports` ตี 1 ทุกคืน) จะใช้โค้ดใหม่รอบถัดไปเอง
   - ถ้าอยากทดสอบเร็วขึ้นโดยไม่กระทบข้อมูลจริง: เลือกฟังก์ชัน `rebuildNow` จาก dropdown ด้านบน editor
     แล้วกด ▶ รัน (ฟังก์ชันนี้แค่สร้าง `saisang_data.json` ใหม่จาก `pos_daily.json` ที่มีอยู่แล้ว **ไม่ยิง OCR
     ไม่แตะอีเมล ปลอดภัย**) — ดูที่แท็บ "การดำเนินการ" (Executions) ว่าจบแบบ "เสร็จสมบูรณ์" (ไม่ใช่ "ล้มเหลว")

**เสร็จส่วน A แล้วแจ้งกลับ:** ชื่อไฟล์ที่แก้ + เวลาที่กด Save + ผลของข้อ 8 ถ้าลองรัน `rebuildNow`

## ส่วน B — Netlify (ไม่จำเป็นเร่งด่วน — กระทบแค่กราฟเดียวบนเว็บ ไม่กระทบ LINE alert)

**บัญชีที่ต้องใช้:** Netlify team `saiyangsoi` · เว็บไซต์ `inspiring-mooncake-52e91e.netlify.app`

1. จาก repo ดาวน์โหลด 2 ไฟล์นี้มาไว้ในโฟลเดอร์เดียวกันบนเครื่อง:
   - `dashboard/saisang_dashboard.html` → **เปลี่ยนชื่อไฟล์เป็น `index.html`**
   - `dashboard/_headers` → ใช้ชื่อเดิม (`_headers` ไม่มีนามสกุล)
2. เลือกไฟล์ทั้งสอง (`index.html` + `_headers`) กดขวา → บีบอัดเป็น zip
   ⚠️ **ไฟล์ต้องอยู่ระดับบนสุดของ zip โดยตรง** ห้ามอยู่ในโฟลเดอร์ย่อยข้างในซิป (Netlify จะหาไม่เจอ)
3. เปิด https://app.netlify.com login ด้วยบัญชีที่อยู่ team `saiyangsoi`
4. เข้าไซต์ `inspiring-mooncake-52e91e` → แท็บ **Deploys**
5. ลาก (drag & drop) ไฟล์ zip จากข้อ 2 ลงบนพื้นที่ deploy (มีข้อความ "Drag and drop your site output folder here")
6. รอจนสถานะขึ้น **Published** (สีเขียว)
7. เปิดเว็บ `https://inspiring-mooncake-52e91e.netlify.app/?v=20260902` (เติม `?v=วันที่วันนี้` กันแคชเก่า)
   เช็คว่าเว็บเปิดได้ปกติ ไม่ขึ้นจอขาว/error ในคอนโซล

**เสร็จส่วน B แล้วแจ้งกลับ:** เวลาที่ deploy สำเร็จ + สกรีนช็อตหน้าเว็บที่เปิดได้ปกติ
